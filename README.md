# Anil Bhattarai — Personal Portfolio

This is a fully static website designed to be hosted for free with GitHub Pages.

## Edit the website
Open `index.html` in any text editor and change:
- About Me
- Education dates
- Experience details
- Skills
- Projects
- Thesis
- Certifications/Courses
- Career Goal
- LinkedIn URL
- Email and phone number

## Add your photo
Put your photo in `assets/profile.jpg` (JPG/PNG also works if you change the filename in index.html).

## Add your CV
Put your PDF at `assets/Anil-Bhattarai-CV.pdf`.

## Free publishing
1. Create a free GitHub account.
2. Create a repository named `YOURUSERNAME.github.io`.
3. Upload `index.html`, `style.css`, and the `assets` folder.
4. In the repository settings, enable Pages from the main branch.
5. Your site will be available at `https://YOURUSERNAME.github.io/`.

No paid hosting is required.
